# БАРС МЭИ → Telegram

Бот раз в 20 минут заходит в БАРС, смотрит «Оценки БАРС» и «Пропуски занятий»
и пишет в Telegram, только если что-то поменялось:

```
📌 Оценки
📚 Web-технологии
🆕 5. Спринт 5. Базы данных и Django ORM: 4 (01.11.26)
   текущий балл: 5,00 → 4,50
📚 Базы данных
✏️ Контрольная неделя №1: 0,00 → 4,00

⚠️ Пропуски
🆕 30.10.26, 2 пара, лабораторная работа — Схемотехника
✏️ 22.10.26, 1 пара, практическое занятие — Спортивные секции: пропуск → пропуск по уважительной причине
```

Следит за «Учёба → Оценки БАРС» (оценки за КМ, контрольные недели, ПА, итоговая) текущего семестра
и за «Посещение занятий» (все пропуски, включая смену на «по уважительной причине»).

Команды в Telegram: `/check` — проверить сейчас, `/status` — когда была последняя проверка.

## Личные функции

### Управление кнопками

После запуска отправь боту любое сообщение (или нажми «Запустить») — появится
меню с кнопками прямо под сообщением:

- **Важные предметы** — таблица оценок, пропусков и прогноз до автомата.
- **Пропуски БАРС** — количество неуважительных пропущенных пар по каждому предмету за текущий семестр и общий итог; без списка дат. Уважительные пропуски не учитываются. Ручной журнал физры не добавляется к данным БАРС.
- **Пропуски физры** — общий счётчик и записи по датам; добавление и удаление.
- **Список дел** — добавление, выполнение, возврат в открытые, дедлайн и удаление.
- **Проверить БАРС** и **Статус** — ручная проверка и сведения о работе бота.

Для добавления физры выбери дату (есть кнопка «Сегодня»), затем количество пар.
Для дела введи текст и дату дедлайна либо нажми «Без дедлайна».
Удаление записи или дела требует нажатия «Да, удалить».
При нажатии кнопки выбранный раздел заменяет текст и кнопки в том же сообщении;
пошаговые формы также обновляют его. При сетевом тайм-ауте редактирования новое
меню не дублируется. Если исходное сообщение удалено, бот создаёт новое меню.
Уведомления об изменениях БАРС и вечерние итоги приходят отдельными сообщениями.
На любом шаге есть «Отмена»; ввод действует 15 минут. Длинные списки разбиты на
страницы. Данные сохраняются после перезапуска, незаконченный ввод нужно начать
заново. Старые команды также продолжают работать.

В 21:00 **по Москве** бот присылает итог «изменений не обнаружено», только если за
сегодня были успешные проверки, изменений не было и последняя проверка не завершилась
ошибкой. В сообщении указаны число проверок и время последней. После перезапуска
бот помнит уже отправленный итог и обнаруженные за день изменения. Если бот был
выключен в 21:00, итог отправится при следующем запуске в тот же день после успешной
проверки. За прошедшие дни итоги не досылаются. Время меняется через `DAILY_REPORT_TIME`.

### Важные предметы и автомат

`/subjects` и кнопка «Важные предметы» показывают только компактную таблицу.
Столбцы — Метрология, Схемотехника и Базы данных; строки КМ содержат оценки,
а если оценка ещё не выставлена — короткую метку `КМ1`, `КМ2` и т. д.
Прочерк означает, что такого КМ у предмета нет. Внизу — текущий балл,
необходимый средний по оставшимся КМ («Для авто»), неуважительные пропуски
за семестр и их лимит. Уважительные пропуски в таблице не показываются и не расходуют лимит.
Пояснений и полных названий КМ под таблицей нет. `?` означает, что данных
недостаточно, «Пересдать» — что оставшихся пятёрок недостаточно для автомата.

По умолчанию порог по всем трём предметам — **4,2**, неуважительных пропусков можно
иметь не более **6,25%** занятий. Лимит округляется вниз до целых пар:

| Предмет | Занятий | Допустимо неуважительных пропусков |
| --- | ---: | ---: |
| Метрология | 32 | 2 |
| Схемотехника | 48 | 3 |
| Базы данных | 24 | 1 |

Веса читаются из столбца «Вес, %» на странице оценок БАРС. Формула необходимого
среднего на оставшихся КМ: `(4,2 × 100 − сумма(оценка × вес)) / оставшийся вес`.
Пустая оценка считается ещё не сданным КМ, а не нулём. Прогноз предполагает сдачу
всех оставшихся КМ минимум на 3; если даже пятёрок недостаточно, бот предложит
улучшить уже выставленные оценки. При отсутствии весов или их сумме не 100%
бот не делает неточный прогноз и объясняет, каких данных не хватает.

`/auto` — посмотреть условия. Изменить: `/auto номер средний_балл всего_занятий`,
например `/auto 2 4.2 48`. Номера: 1 — Метрология, 2 — Схемотехника, 3 — Базы данных.
В первый раз после обновления выполни `/check`, чтобы получить веса КМ в снимке.

### Отдельный журнал физры

Этот журнал заполняется вручную и не объединяется с пропусками БАРС:

- `/pe` — список записей и общее количество пропущенных пар.
- `/pe add 02.11.2026` — добавить одну пропущенную пару.
- `/pe add 02.11.2026 2` — добавить две пропущенные пары.
- `/pe del 1` — удалить запись №1 (целиком).

### Список дел

- `/todo` — открытые дела, сначала с ближайшими дедлайнами. Просроченные помечаются.
- `/todo add Сдать лабораторную | 10.11.2026` — дело с дедлайном.
- `/todo add Подготовиться к контрольной` — дело без дедлайна.
- `/todo deadline 1 15.11.2026` — установить или изменить дедлайн дела №1.
- `/todo deadline 1 -` — снять дедлайн.
- `/todo done 1` — отметить выполненным; `/todo open 1` — вернуть в открытые.
- `/todo del 1` — удалить дело; `/todo all` — показать и выполненные.

Даты также принимаются в формате `2026-11-10`. Дедлайн действует до конца указанной
даты по Москве; отдельные напоминания о дедлайнах не отправляются.
Дела, физра, условия автомата и статистика дней хранятся в `personal.json`, отдельно
от снимков БАРС. Все личные команды доступны только владельцу из `TG_CHAT_ID`.
`/help` открывает главное меню с кнопками.

## 1. Создай Telegram-бота
1. Напиши [@BotFather](https://t.me/BotFather) → `/newbot` → придумай имя.
2. Скопируй токен вида `123456789:AA...`.

## 2. Установи на VPS (Ubuntu/Debian)
```bash
sudo useradd -r -m -d /opt/bars-bot bars
sudo cp -r bars-bot/* bars-bot/.env.example /opt/bars-bot/
cd /opt/bars-bot
sudo python3 -m venv venv
sudo venv/bin/pip install -r requirements.txt
sudo cp .env.example .env && sudo nano .env      # логин, пароль, BARS_TOTP_SECRET, TG_TOKEN
sudo chown -R bars:bars /opt/bars-bot && sudo chmod 600 /opt/bars-bot/.env
```

## Двухфакторная аутентификация
В БАРС 2FA обязательна. Чтобы бот входил сам, подключи в БАРС способ «Одноразовые коды TOTP»
(профиль → «Аутентификация»), нажми «Данные для добавления вручную» и впиши «Секретный ключ»
в `BARS_TOTP_SECRET`. Галочку «Запомнить меня» бот ставит сам, а сессию сохраняет в `cookies.pkl`,
так что после перезапуска код заново не нужен.

Без ключа бот тоже работает: когда БАРС попросит код, он напишет в Telegram, а ты ответишь цифрами из MAX/ВК.

Время на сервере должно быть точным, иначе TOTP-коды не подойдут: `timedatectl` должен показывать
`System clock synchronized: yes`.

## 3. Проверь, что вход и страницы читаются
```bash
sudo -u bars venv/bin/python bars_bot.py --dump
```
Должно вывести семестр, список дисциплин и число пропусков. HTML сохранится в `dumps/`.
Если что-то не так — пришли файлы из `dumps/`, подправлю разбор.

## 4. Узнай свой chat id
```bash
sudo -u bars venv/bin/python bars_bot.py
```
Напиши боту в Telegram `/start` — он ответит числом. Впиши его в `TG_CHAT_ID`, останови бота (Ctrl+C).

## 5. Запусти как сервис
```bash
sudo cp bars-bot.service /etc/systemd/system/
sudo systemctl daemon-reload
sudo systemctl enable --now bars-bot
journalctl -u bars-bot -f        # логи
```
Первая проверка просто запоминает текущее состояние, дальше приходят только изменения.

## Если что-то не так
- **«Не удалось войти»** — проверь логин/пароль в `.env` (тот же, что на bars.mpei.ru).
- **«Неверный код»** — проверь ключ в `BARS_TOTP_SECRET` и время на сервере (`sudo timedatectl set-ntp true`).
- **«Не понял страницу двухфакторной проверки»** — бот сохранит её в `dumps/2fa_unrecognized.html`; пришли этот файл, подправлю.
- **БАРС недоступен** — бот напишет после 3 неудачных попыток подряд и сообщит, когда всё восстановится.
- Состояние хранится в `state.json`; удали его, чтобы бот «забыл» всё и начал заново. Сессия — в `cookies.pkl`.
